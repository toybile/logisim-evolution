# Logisim Panels — 0.1.0

English is the default. Extract the entire archive before opening the application.

Windows: open **Logisim Panels.exe**. To view the example, open `examples/Exemplo.circ` from File → Open.

Linux x64: run `./start.sh` from the extracted folder. Run `./example.sh` for the example.
Run `./install-menu.sh` once to add a shortcut to your application menu.
A graphical desktop with X11/XWayland and font libraries is required; Java is included.

The layout symbol on the floating toolbar opens **Settings and appearance…**.
There you can select **English** or **Português (Brasil)**, a workspace theme,
selection and signal colors, opacity, and animations. Your settings are saved in your user profile.

Drag panel headers to move them. Resize using any edge or corner, including the bottom-right grip.
Minimize with `−`, close with `×`, and reopen using the selected toolbar symbols.
The toolbar itself can be moved and resized horizontally or vertically.

Library includes collapsible Quick access and the original explorer in **Legacy**.
Properties keeps the native attribute editors and undo. Simulation operates on the real circuit.
Truth table includes the propositional equation and CSV export for combinational circuits with up to 10 input bits.

This is an evaluation release. Windows has been tested locally. Linux packaging is available,
but its graphical interface has not yet been tested on an actual Linux desktop.
See the Portuguese README and verification report for more details.
